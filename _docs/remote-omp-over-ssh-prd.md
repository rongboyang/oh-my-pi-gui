# PRD：通过 SSH 在 omp GUI 中使用远端 omp

状态：需求草案 · 首版验收平台：macOS GUI 客户端 → macOS 远端主机

## 1. 问题与目标

用户在远端主机上启动一个支持 GUI 接入的 omp 实例，在客户端打开 omp GUI，通过 SSH 接入远端主机上**已经运行的实例**。用户用熟悉的 GUI 对话、看输出、做审批；实际理解代码、运行工具、修改项目和保存会话的都是远端主机上的 omp。客户端不需要克隆项目，也不需要安装项目依赖或配置模型凭据。

这不是通过 SSH 编辑文件，也不是让本机 omp 调用一个远端 Shell。现有 GUI 默认启动本机 `omp --mode rpc-ui`，通过标准输入输出交换 RPC；现有 SSH 主机设置服务于远端终端，不会把 omp 实例、工作区或会话切到远端。远程模式要改变的是 **GUI 连接的 Agent**，而不是单独改变某个工具的执行位置。

| 事项 | 客户端 | 远端主机 |
| --- | --- | --- |
| 对话、审批、输出 | 展示状态并发送用户操作 | 运行 Agent，生成输出，执行审批结果 |
| 工作区、命令、Git、依赖 | 不需要本地副本；不在本机执行远端会话的工具 | 使用远端工作区、远端账号及其运行环境 |
| 模型与工具配置 | 不复制本机 Provider、MCP 或项目凭据到远端 | 使用远端 omp 的配置、凭据和网络出口 |
| 会话与历史 | 可保存连接配置和恢复目标；不作为会话事实来源 | 保存会话、任务进度和结果；重连后由远端恢复界面状态 |

## 2. 交付范围

| 阶段 | 可独立发布的能力 |
| --- | --- |
| **阶段一：远端 Agent 核心链路** | 接入已运行的专用 omp 实例；发送消息并看流式回复；远端工具执行、输出和审批；断开、重连、续聊和显式停止任务。通过阶段一验收即可发布。 |
| **阶段二：远端文档预览** | 从聊天或工具结果中打开远端 Markdown 和纯文本文件，在 GUI 内只读预览。阶段一不依赖此功能。 |

**非目标**：接管普通 TUI 或 tmux 中运行的 omp；由 GUI 启动、安装、更新或管理远端实例；多客户端同时操控一个实例；独立远端文件树、手动路径浏览器、文件上传下载或同步、通用远端编辑器、独立 Git 面板；PDF/Office 预览；Linux、Windows 端首版兼容承诺。远端工具可以修改源码、运行 Git 和测试，不因这些 GUI 面板未纳入范围而受限。

## 3. 阶段一：产品需求

### 3.1 启动与连接

1. 用户在远端主机上选定项目目录，用产品文档给出的方式启动支持 GUI 接入的专用 omp 实例。实例的运行与 SSH 客户端连接生命周期独立；关闭 GUI 不负责停止实例。
2. 用户在客户端的 GUI 选择「连接远端 omp」，选取 SSH 主机或填入已有的 OpenSSH 主机别名，连接远端实例。首版以一个实例绑定一个远端工作区为边界；若同一 SSH 目标有多个实例，必须让用户明确选择，不自动挑一个。
3. 连接完成后，在会话界面持续显示「远端」、SSH 主机别名和远端工作区路径。本地与远端会话可分别使用；会话归属不得只按目录字符串判断，不同主机上的同名目录不得串线。
4. 连接流程区分「正在连接」「已连接」「正在重连」「已断开」。失败说明卡在哪一层以及下一步：例如先用 OpenSSH 验证主机访问、在远端启动实例、选择正确实例或安装协议兼容的版本。SSH 登录成功但没有可用 omp 实例，不算连接成功，不静默启动实例或回退到本机 omp。

### 3.2 在远端工作

1. 用户连接后能查看该实例的当前会话、继续对话、发起新会话。消息、流式回复、工具调用、工具输出和任务状态按同一远端会话展示，不混入本机历史。断开或关闭 GUI 后，能用已保存的连接目标回到原实例和会话。
2. 文件读取和编辑、Shell 命令、Git、测试等由远端 omp 执行，使用远端路径和权限。远端缺少依赖、凭据或工具时，如实展示远端错误；不借用本机环境补跑。
3. 审批或交互请求在 GUI 展示发起它的远端会话及操作内容。用户的确认、拒绝或输入只交给该请求；等待期间不替用户批准。未能确认发送结果时，重连后先查询远端状态，不自动重复发送审批、消息或其他有副作用的操作。
4. 「断开连接」与「停止当前任务」是两个动作。停止是发给远端实例的显式请求，GUI 只在远端确认后显示任务已停止。一个实例同一时间最多允许一个 GUI 客户端写入；第二个客户端收到明确提示，不抢占第一个连接。

### 3.3 断线、重连与恢复

- **GUI 退出、SSH 断开、客户端切网**：只断开界面连接。只要远端主机在线且原实例还在运行，已接受的任务继续。遇到需要用户确认或输入的步骤，停在该步骤等待用户回来，不默认放行。
- **回到同一实例、同一会话**：优先恢复对话内容、当前任务状态、断线期间产生的工具结果和待处理请求，再接续实时更新。任务已完成则展示结果，不重跑；任务仍在跑则继续展示进度；审批已处理或失效则不再显示为待确认。
- **远端关机、休眠或实例退出**：GUI 不承诺此时任务仍在执行，也不把无法确认的运行状态显示为完成或失败。实例重启后，可恢复已持久化的会话；旧实例中的执行任务不自动重跑，未持久化的进度不承诺恢复。

## 4. 阶段二：远端文档预览

1. 用户点击聊天消息或工具输出中指向当前远端工作区的文件路径，在 GUI 内看到 Markdown 渲染或纯文本预览。预览显示远端主机及文件路径；同名本地文件存在时仍读取远端文件。相对路径以当前远端工作区为基准。
2. 预览内容从当前远端连接按需读取，不要求挂载或同步目录，不写回文件，不在本机物化工作区副本。断连时不假装能读取远端最新内容；重新打开时读取远端当前内容。
3. 预览仅支持工作区内、远端账号可读的 Markdown 和纯文本文件；不跟随符号链接读出工作区。文件不存在、无权限、过大、不支持的类型或连接已断开时，展示对应原因，不回退到本机路径。Markdown 使用 GUI 的安全渲染路径，不执行文档中的脚本，也不自动加载外部资源。

## 5. 安全与实现约束

- 复用 OpenSSH 的主机校验和用户认证，不绕过首次信任确认，不忽略主机密钥变化，不默认转发 SSH agent。GUI 不保存 SSH 密码、私钥内容或远端模型凭据；连接诊断不得记录凭据、消息正文或工具输出正文。
- 不要求在远端对外开放额外的 omp RPC 端口；远端实例的接入点仅向有权访问它的远端账号开放。工作区提示不是权限沙箱：Agent 的实际工具权限仍由远端账号和 omp 的审批策略决定。阶段二的预览范围另行做工作区边界检查。
- 实现方向：本机模式保留现有 sidecar；远端模式由 SSH 传输 GUI 与远端 omp 的请求和事件。须验证现有 `rpc-ui` 能否提供可重连接入、状态恢复和版本协商；不能把一次普通的 `ssh … omp --mode rpc-ui` 进程启动当作接入常驻实例。若需改 Core，远端生命周期与会话状态归 Core，连接体验与展示归 GUI；协议和常驻方式由技术设计确定。
- 现状依据：`src/main/sidecar.ts` 本地启动 `rpc-ui` 并经 stdin/stdout 处理 RPC；`src/main/index.ts` 将会话索引接入本机文件系统；`src/shared/rpc-types.ts` 的 SSH 终端信息描述的是工具 Shell，不是 Agent 实例连接。

## 6. 发布验收

使用两台独立 macOS 电脑。客户端不放测试项目、不配置该项目所需的模型凭据；远端主机上准备项目、依赖、凭据和专用 omp 实例。另用本机模式做回归。每个阶段独立判定。

| 阶段 | 场景 | 通过条件 |
| --- | --- | --- |
| 一 | SSH 接入远端主机上已运行的实例 | GUI 显示正确的主机和工作区，能看到预先在远端创建的会话；没有启动第二个远端实例或把本机 sidecar 当作该会话的后端。 |
| 一 | 在 GUI 中发起真实编码任务 | Agent 读取只在远端主机上存在的文件，在远端主机上改代码并跑测试；GUI 展示流式回复和工具输出；在远端主机上独立检查 `git diff` 和测试结果，客户端无项目副本或对应修改。 |
| 一 | GUI 退出或客户端断网时任务正在执行 | 任务在远端主机上继续运行；重开 GUI 或恢复网络后回到同一会话，看到断线期间产生的结果，操作未执行两次；任务仍运行时可显式停止并看到远端确认。 |
| 一 | 断线期间出现审批 | 远端主机不执行需要批准的操作；重连后看到同一待处理请求。批准只执行一次；用另一请求验证拒绝不会执行。 |
| 一 | SSH 认证失败、主机密钥变化、实例未启动或版本不兼容 | GUI 给出对应原因和处理方向；不绕过 SSH 检查，不创建新实例，不切回本机。 |
| 一 | 远端实例退出；第二个 GUI 尝试写入；本机与远端同名目录 | 实例退出不伪报成功，重启后仅恢复已保存会话；第二个 GUI 不能并发操控；本机与远端消息、历史和工具归属不串线，本机模式照常使用。 |
| 二 | 从聊天和工具结果打开远端文档 | Markdown 和纯文本均在 GUI 内预览；与本机同名或路径相同时读取远端主机上的实际内容，修改远端主机上的文件后重新打开能看到更新，不产生本机项目副本。 |
| 二 | 路径越界、符号链接越界、文件不存在、类型不支持或远端断开 | 对应错误可辨认；不读取本机文件、不显示工作区外内容；含脚本或外部资源的 Markdown 不执行脚本、不自动发起外部请求。 |
